Etichetta a pillola per un settore, un ruolo o una novità.

- Settore o tema: fondo `accent-soft`, testo `accent-text`.
- Agente: fondo `brand-soft`, testo `brand-text`.
- Novità: fondo `accent`, testo `on-accent`.
- Dato tecnico: contorno `line-strong`, monospazio di sistema.

Al massimo due tag per contenuto. Non sono cliccabili. Non hanno il punto.
