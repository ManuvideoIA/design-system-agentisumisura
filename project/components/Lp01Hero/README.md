Hero tipografico con parola evidenziata. Prima schermata della landing page, senza immagini.

**Quando usarla.** Come prima schermata quando la promessa è il prodotto e qualunque immagine indebolirebbe la frase. Anche quando non hai asset visivi decenti.

**Struttura.** Titolo enorme spezzato a mano su tre righe, con una sola parola dentro un blocco di colore pieno. Sottotitolo su una colonna più stretta del titolo. Due pulsanti affiancati e centrati, che si impilano sotto i 380 px.

**Campi da scrivere.** 3 righe di titolo, 1 parola evidenziata, 1 sottotitolo, 2 CTA, 1 riga di microcopy.

**Interazione.** Nessuna.

**Misure indicative.** Titolo 28/72 px, interlinea 1.05, larghezza massima 760 px. Sottotitolo massimo 42 caratteri per riga. Blocco pieno con padding .04em/.2em. Pulsanti con gap 12 px.

**Da personalizzare per Alterego.**

- Il blocco pieno nero del file diventa `accent` con testo `on-accent` (lo dice il file stesso).
- Titolo in `display-xl`. Pulsante principale `brand` con `on-brand`, secondario a contorno.
- Il copy è da scrivere. Usa l'offerta in una frase e le regole di scrittura del README.
