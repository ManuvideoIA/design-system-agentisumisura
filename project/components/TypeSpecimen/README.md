Campione dei font, gli stessi di Shegöne. Baskervville per i titoli grandi. Space Grotesk per gli altri titoli. Figtree per il testo. Space Mono per etichette e dati.

Sono file locali in `fonts/`, dichiarati in `tokens.json`. Se un font non carica, si usa il font di sistema. Space Mono non ha il peso 500: i dati usano 400 o 700. Sono scelte creative non verificate rispetto al tuo pubblico.
